# Changelog

## v0.1.1

- First release on CurseForge. No changes in game since v0.1.0.

## v0.1.0

- First release for WoW Forever (beta) and Classic Era / Hardcore.
- Item tooltips show which of your professions use the item, with known,
  learnable and later recipe counts, and the recipe list on Shift.
- Alts on the same realm and faction, planned professions, and an option to
  ignore gray recipes.
- Hardcore aware: dead characters stop counting as alts, Self-Found characters
  only consider their own professions.
